# Projeto CRUD com Spring Boot

Este é um projeto simples de **CRUD (Create, Read, Update, Delete)** desenvolvido com **Spring Boot**, **Java** e **MySQL**.  
O objetivo é demonstrar o funcionamento básico de uma API REST.

---

## 🚀 Tecnologias utilizadas
- ☕ **Java 17+**
- 🌱 **Spring Boot**
- 🗄️ **Spring Data JPA**
- 🐬 **MySQL**
- 🔁 **Spring Web**
- 🧪 **Postman** (para testes)
